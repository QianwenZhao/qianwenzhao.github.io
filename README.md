# Qianwen Zhao Portfolio

Personal portfolio website for Qianwen Zhao, built with Jekyll from the Academic Pages theme.

## Local Preview

Install the Ruby dependencies, then run:

```bash
bundle exec jekyll serve -l -H localhost
```

The site is available at `http://localhost:4000`.

## Content

The active site pages live in `_pages/` and use the `QZ-*.md` naming convention. Personal images live in `images/` and use `QZ-*` filenames.
